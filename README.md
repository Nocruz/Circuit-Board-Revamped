# Circuit Board: Revamped
Hi!  This is **Circuit Board: Revamped**, a sandbox Roblox experience targeted to anyone willing to learn about *logic* using an interactive environment, rather than pesky textbooks.
- I've made this project open-source thanks to [Rojo](https://github.com/rojo-rbx/rojo), so check them out.

- This project is heavily inspired by another Roblox experience, [Circuit Board](https://www.roblox.com/games/112399477218954/Circuit-Board) by [@Thebenjiball](https://www.roblox.com/users/153683700/profile).
